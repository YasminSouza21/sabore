# Saborê

Projeto Flutter mobile de receitas. Esta primeira etapa define a identidade visual e o layout da tela principal com textos e cartões provisórios.

## Executar

```sh
flutter pub get
flutter devices
flutter run -d ID_DO_DISPOSITIVO
```

Projeto criado com Flutter 3.47.5 e Dart 3.13.4 para Android e iOS.
